## 공통 상세 설명

남식당은 남도학숙 은평관과 동작관의 식단을 한곳에서 확인할 수 있는 생활 편의 서비스입니다.

오늘의 아침, 점심, 저녁 메뉴를 확인하고 원하는 날짜의 식단을 찾아보세요.

주요 기능
- 은평관·동작관 식단 전환
- 아침·점심·저녁 메뉴를 보기 편한 카드로 표시
- 날짜 선택과 오늘 날짜로 돌아가기
- 오늘 기준 3개월 전부터 3개월 후까지 날짜 조회
- 마지막으로 선택한 관 기억
- 식단 미등록 안내와 조회 실패 시 다시 불러오기

등록되지 않은 날짜에는 식단이 표시되지 않을 수 있습니다. 식단은 학숙 사정에 따라 변경될 수 있습니다.

문의·제안: contact@wookingwoo.com

## 심사 메모 초안

이 앱은 남도학숙 은평관·동작관의 식단을 조회하는 앱입니다. 회원가입이나 로그인이 필요하지 않습니다. 첫 실행 시 은평관이 선택되며, 화면의 관 선택 버튼으로 동작관 식단을 확인할 수 있습니다. 날짜 선택 영역에서 날짜를 바꾸면 해당 날짜의 아침·점심·저녁 식단을 조회합니다. Firebase Firestore에 식단이 없는 날짜에는 미등록 안내를 표시합니다. 네트워크 연결이 필요합니다.

제출 직전에 심사자가 확인할 수 있는 실제 식단 등록 날짜를 확인해 메모에 추가한다. 테스트용 예시 식단이나 스크린샷을 운영 식단으로 설명하지 않는다.

## 개인정보 신고용 사실 확인

- 관 선택은 AsyncStorage의 `selectedCampus` 키에 로컬 저장된다.
- 화면은 Firebase JS SDK로 Firestore 식단 문서를 읽는다.
- 현재 앱 코드에는 회원가입, 결제, 광고, 사용자 위치·연락처·카메라·마이크 수집 기능이 없다.
- SDK가 처리하는 식별자·로그·진단·네트워크 정보와 최종 Android 권한/iOS Privacy Manifest를 별도로 점검해야 한다.
- 따라서 '데이터를 수집하지 않음' 여부를 이 문서만으로 확정하지 않는다. Google Data safety와 Apple App Privacy는 최종 배포물 및 실제 운영 설정을 기준으로 작성한다.
- 식단 데이터·남도학숙 명칭·로고 사용 권한과 공식 서비스 여부에 관한 설명을 소유자가 확인한다.

## 스크린샷 촬영 목록

- 은평관: 오늘의 세 끼가 등록된 화면.
- 동작관: 관 선택 후 실제 식단 화면.
- 날짜 변경 화면.
- 서비스 정보 화면.
- Android와 iPhone 출시 빌드에서 각각 촬영. iPad를 지원하기로 결정하면 해당 스크린샷도 준비.
- 기존 `docs/ui-review/` 이미지는 웹 UI 검증용이며 테스트 식단을 포함한다. 실제 기기 스토어 스크린샷으로 그대로 제출하지 않는다.
